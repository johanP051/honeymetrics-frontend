# 🍯 HoneyMetrics 2.0 — Frontend SPA

Documentación de la Single Page Application (SPA) en React 18, Vite y compilador SWC (Rust).

---

## 🎨 Principios de Diseño y Componentes
1. **Componentes Atómicos:** Separación estricta por dominios (`layout/`, `threats/`, `common/`).
2. **Custom Hooks:** Lógica de datos aislada de la capa visual.
3. **Mocks Inteligentes:** Simulación de datos para desarrollo offline.
